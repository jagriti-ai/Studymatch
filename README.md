# StudyMatch

A web app that helps students find study partners who share their subjects, level, goal and free time.
Made by Jagriti for the Orbix Hackathon.

## What it does
- You enter your subjects, level, what you are studying for, and when you are free.
- It scores every student: 2 points per shared subject, 1 per shared free slot, 1 for the same level, 1 for the same goal.
- Matches are ranked by score. You can filter by same level or same free time.
- Each match has a Contact button (email or WhatsApp) and a "Copy invite message" button.
- Your profile is saved in the browser, so it is filled in again next time.

## Tech
HTML, CSS and JavaScript only. Open index.html in a browser to run it.

## Limits and next steps
The students shown are sample data. Next I want to add real accounts and a database (Firebase) so people can sign up, plus in-app chat.
